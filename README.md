## 💻 CLI Command Reference

| Command | Action | Description |
| :--- | :--- | :--- |
| `npm run dev` | `🟢 Local Dev` | Fires up local development server at `localhost:3000` |
| `npm run build` | `📦 Production` | Compiles optimized bundle into `/build` or `/.next` |
| `npm start` | `🚀 Launch` | Runs the production-compiled build |
| `npm run deploy` | `⚡ Deployment` | Triggers automated deployment to production |
